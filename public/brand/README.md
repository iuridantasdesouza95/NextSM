# NextSM Brand

Direção oficial: **Proposta 3 — Variação Premium / Tecnológica**.

## Logo aprovado

O logo oficial usado no produto segue a referência aprovada:
- símbolo hexagonal geométrico com seis pontos de conexão;
- N construído geometricamente no interior;
- gradiente azul `#0066FF` → ciano `#00D4FF`;
- wordmark `NextSM`, com `Next` em base neutra e `SM` em gradiente;
- assinatura `SERVICE DESK` em caixa alta com espaçamento amplo;
- tipografia da marca: **Sora SemiBold / Bold**;
- versões clara, escura e monocromática.

## DNA visual

**Estrutura + Conexão + Inteligência + Evolução contínua.**

O hexágono representa estrutura e processos; os pontos representam integração; o N representa Next, evolução, tecnologia e futuro da gestão de serviços.

Os arquivos SVG são vetoriais e devem ser preferidos aos screenshots ou imagens rasterizadas para uso no SaaS.
