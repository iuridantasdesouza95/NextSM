# NextSM

**NextSM — Service Management Platform**

Plataforma de Service Management para gestão de chamados, atendimento, SLA, conhecimento, automações e processos ITSM.

## Direção do produto

A NextSM é um produto SaaS independente, com identidade própria e arquitetura preparada para evolução comercial.

Stack principal:

- Frontend: React + TanStack Start/Router
- Backend: TanStack Start
- Banco/Auth/Storage: Supabase
- Deploy: Vercel
- Versionamento: GitHub

## Desenvolvimento

Requisitos:

- Node.js
- npm ou Bun

```sh
git clone <this-repository-url>
cd NextSM
npm install
npm run dev
```

## Variáveis de ambiente

Configure as credenciais do seu projeto Supabase no ambiente de desenvolvimento/produção. Nunca versionar chaves privadas ou secrets no repositório.

## Estrutura

- `src/` — aplicação
- `supabase/` — migrations e recursos do banco
- `public/brand/` — identidade visual NextSM
- `docs/` — documentação técnica do produto

## Identidade

A identidade visual da NextSM segue a direção **Premium/Tecnológica**, baseada em estrutura, conexão, inteligência e evolução contínua.

A marca utiliza um símbolo hexagonal com N geométrico e linguagem visual baseada em navy profundo, azul tecnológico e branco.
